# TVS Mods Domain

This directory is a domain container for TVS modding workspaces.

- `csharp/` contains the Rush-managed .NET and BepInEx mod development workspace.
- `unity/` contains the shared Unity authoring project used for mod asset composition and batch builds.

Rush projects in this domain:

- `@tvs/mods-csharp` at `mods/csharp`
- `@tvs/mods-unity` at `mods/unity`
